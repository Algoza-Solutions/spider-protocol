# Project Requirements

Every repository-changing request must have one primary requirement entry with a stable `REQ-[N]` identifier. New entries are inserted newest-first immediately under `## Active Requirements` using a second-precision ISO 8601 timestamp (`YYYY-MM-DDTHH:mm:ss±HH:mm` or `Z`).

Lifecycle: `Ready -> In Progress -> Done` (or `Superseded`; `In Progress -> Draft` only when unresolved user intent is surfaced).
